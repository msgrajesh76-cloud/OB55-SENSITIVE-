ADMIN
Click Admin and use the same demo credentials. The admin panel edits device records, three player presets and social links. Changes are stored in browser localStorage.

IMPORTANT
A normal website cannot reliably detect the exact phone model from the browser. This build detects/estimates available RAM and CSS screen dimensions and uses exact model search for device presets. It includes a starter database of popular models and a fallback algorithm for other models.

Sensitivity values are starting recommendations, not guaranteed 100% headshot/no-recoil settings. Real aim depends on touch response, FPS stability, screen protector, grip and player skill. Test and fine-tune in Training Ground.
